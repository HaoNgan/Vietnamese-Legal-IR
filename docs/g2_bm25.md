# Hướng dẫn chạy G2 BM25 trên Zalo

## G2 làm gì?

G2 lấy từng câu hỏi trong tập validation Zalo, tìm tài liệu liên quan trong toàn bộ corpus Zalo bằng BM25, lưu thứ hạng, rồi so thứ hạng với qrel validation để tính metric. Kết quả G0 không thay thế lần chạy này vì G0 dùng BKAI/YuITC.

## Trước khi chạy

Mở PowerShell tại thư mục `legal_ir` và dùng môi trường Python của project. Kiểm tra dữ liệu G1 chưa bị thay đổi:

```powershell
python -m src.data.prepare_g1 --verify
```

Lệnh phải xác nhận checksum các tệp dữ liệu đã khóa. Nếu báo lỗi, dừng và xử lý sai khác trước khi chạy benchmark.

## Tạo BM25 ranked run

```powershell
python -u -m src.evaluation.run_g2_bm25 --top-k 100
```

Runner đọc corpus, query và qrel validation từ `data/processed/benchmarks/zalo_2021/`. Nó lập chỉ mục toàn bộ 61.425 tài liệu, rồi lấy tối đa 100 tài liệu cho mỗi 256 query validation. Mặc định dùng BM25 `k1=1.5`, `b=0.75` và bộ tiền xử lý/tách từ của checkout Daijestic đã pin. Lập chỉ mục CPU có thể mất nhiều phút.

Kết quả nằm tại:

- `outputs/g2_bm25/bm25_validation_run.csv`: các cột `qid,doc_id,rank,score`.
- `outputs/g2_bm25/run_config.json`: split, tham số, revision code và checksum đầu vào/run.

## Tính metric

Sau khi runner chạy xong:

```powershell
python -m src.evaluation.evaluate_runs `
  --qrels data/processed/benchmarks/zalo_2021/qrels_validation.jsonl `
  --run outputs/g2_bm25/bm25_validation_run.csv `
  --corpus data/processed/benchmarks/zalo_2021/corpus.jsonl `
  --output outputs/g2_bm25/evaluation.json
```

Evaluator ghi Recall@10, Recall@50, MRR, MAP và nDCG@10 trung bình vào `evaluation.json`; từng query được ghi ở `evaluation_per_query.csv`. Chia sẻ cả run, config và báo cáo để người khác tái kiểm tra.

## Chọn tham số và bảo vệ test

Có thể chạy lại với cấu hình khác, ví dụ:

```powershell
python -u -m src.evaluation.run_g2_bm25 --top-k 100 --k1 1.2 --b 0.75
```

Mỗi lần chạy sẽ ghi đè các tệp cùng tên trong `outputs/g2_bm25/`; nếu cần so sánh nhiều cấu hình, hãy dùng `--output-dir outputs/g2_bm25_k1_1_2` để giữ riêng kết quả. Chọn cấu hình dựa trên validation. Không dùng `qrels_test.jsonl` để tuning; chỉ dùng test sau khi đã cố định phương pháp và cấu hình cho đánh giá cuối.

## Khi nào G2 đạt?

G2 đạt khi có ranked run BM25 trên toàn corpus Zalo cho validation, báo cáo metric từ evaluator, cùng cấu hình và checksum cho phép kiểm tra lại. Chạy thành công G0 trên subset BKAI/YuITC không đáp ứng điều kiện này.
